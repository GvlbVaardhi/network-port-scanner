# Python Network Port Scanner

A Python-based TCP network port scanner developed for learning network security, socket programming and TCP/IP concepts.

## Features

- TCP port scanning
- Custom port ranges
- Concurrent scanning using ThreadPoolExecutor
- Connection timeout handling
- Hostname and IP resolution
- Basic service identification
- Scan result reporting
- Command-line interface

## Technologies

- Python
- Socket Programming
- TCP/IP
- ThreadPoolExecutor
- Linux

## Usage

```bash
python3 scanner.py 127.0.0.1 -p 1 1000
